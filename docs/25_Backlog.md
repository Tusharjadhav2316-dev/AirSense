# 25 — Backlog (Deferred, Not v1)

Ideas that come up mid-build go here, not into the current sprint. Only
pull from this list in the Sprint 4 Day 18 buffer, and only if genuinely
low-risk/low-effort.

## How to Add to This List
When an idea comes up: one line, one sentence why it's valuable, and
explicitly note "deferred" — don't silently drop it, but don't build it
now either.
